Meta + Q = Terminal
Meta + E = File Explorer
Meta + R = Runner

Meta + up = Move window up
Meta + down = Move window down
Meta + left = Move window to the left
Meta + right = Move window to the right
Meta + f = Fullscreen window

Switch Desktops
```
Meta + 1
Meta + 2
Meta + 3
Meta + 4
```

Move window to said Desktop
```
Meta + Shift + 1
Meta + Shift + 2
Meta + Shift + 3
Meta + Shift + 4
```
