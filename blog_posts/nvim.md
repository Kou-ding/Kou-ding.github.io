# Neovim

Useful commands:
- `:LazyHealth` Makes sure that **lazyvim** has the necessary packages to function optimally
- `:Tutor` Teaches you the neovim basics

### Modes

- **v**: visual mode (selection mode)
- **ctr+v**: multiline visual mode (selection mode)
- **i**: insert mode
    - **A**: start insert mode at the end of a line
    - **a**: start insert mode after the cursor
    - **O**: start insert mode and create a new line above 
    - **o**: start insert mode create a new line below

### Cursor movement

- Small movement
    - **h**: left
    - **j**: down
    - **k**: up
    - **l**: right

- Medium movement
    - **w**: start of next word
    - **e**: end of next word

- Large movement
    - **gg**: beginning of a document
    - **G**: end of a document
    - **0**: start of a line
    - **$**: end of a line 


### Text manipulation

- **x**: delete letter
- **X**: delete previous letter
- **dd**: delete row


### Basic Utilities

- **\>\>**: tab
- **<<**: untab
- **y**: yank (copy)
- **p**: paste
- **u**: undo
- **ctr+r**: redo
- **/**: search
- **n**: next in search
- **N**: previous in search
